# Competitive Analysis (SMB BI)

| | Zoho Analytics | Power BI | Metabase | Looker Studio | **InsightForge** |
|---|---|---|---|---|---|
| SMB pricing fit | ✔ | partial | ✔ (OSS) | ✔ (free) | ✔ |
| Setup burden | medium | high | medium | low | **low (one compose command)** |
| Data quality surfacing | weak | add-on | none | none | **core: score+quarantine+recipes** |
| Lineage for end users | no | enterprise tier | no | no | **2 clicks from any chart** |
| Governed formulas | partial | DAX (expert) | SQL (expert) | limited | **small governed language** |
| Trust telemetry on shares | no | no | no | no | **readout on every snapshot** |
| Honest forecasting UX | black-box | black-box | none | none | **labelled + banded** |

Positioning sentence: *"Zoho shows you charts; InsightForge shows you charts
you can defend in a bank meeting."*

Threats: incumbents adding "quality badges" (mitigate: depth — recipes,
quarantine, lineage are structural, not cosmetic); LLM-BI startups
(mitigate: SMBs punish hallucinated numbers; our honesty stance is the moat).
